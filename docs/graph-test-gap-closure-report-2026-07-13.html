Closing the agent-graph contract's testing gaps

A measured coverage pass found the adapter → server graph-engine → frontend contract strong in breadth but thin in verification — the render layer that once blanked 65.8% of traces was checked only by hand, and 9 of 19 frameworks had no server-side honesty fixture. All seven gaps are now closed test-first, one PR per cluster, each proven to fail before it was made to pass.

Discipline held throughout. Every new test was watched to fail when the feature is broken, then made green — node labels, colour maps, empty-states, content redaction, honesty guards, and live node-sets each verified with a red-before-green demonstration. No fixture was hand-authored: node-sets were captured from real adapter output and transcribed from what the real engine produces.

How the fixtures were captured (reproducible, cred-free where possible)

capture

Ran each framework's real recorded-replay test over its sealed provider response, wrapping the upload to seal the emitted event stream — real adapter, real shape, no creds.

infer

Fed those events through the real Go engine (InferAgentGraph, both honestGuard variants) and read back the actual node-set, column, edges, and topology.

transcribe

Copied the engine's output into the Go matrices and the FE fixtures — so the tests assert what the engine really does, and can never drift into a self-fulfilling mirror.

break & watch

Broke the feature (a label, a colour, an identity, a strip-set, the oracle) and watched the assertion go red before wiring it green — the CLAUDE.md rule-4 gate on every cluster.
